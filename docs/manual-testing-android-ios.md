# Ручной чек-лист Android Chrome / iOS Safari

Автоматические E2E не заменяют проверку на реальном устройстве: поведение storage, воспроизведение медиа и PWA-установка зависят от платформы. Выполняется на production-окружении (или на HTTPS-туннеле к dev-стеку, см. README).

Перед проверкой: выпустите доступ ученику (курс с видео/аудио/изображениями), откройте ссылку в Mailpit и перешлите её на телефон (QR/вручную). Пароль владельца для входа в vendor cabinet — свой.

## Android Chrome

1. **Установка PWA.** Откройте ссылку доступа. Появится «Добавить на главный экран» (или через меню ⋮ → «Добавить на главный экран»). Иконка и имя приложения корректны.
2. **Онлайн-просмотр.** Все типы контента (текст, изображение, аудио, видео) открываются. Видео перематывается (Range) и не буферизует весь файл.
3. **Скачивание офлайн.** На странице курса «Скачать курс» → прогресс докачивается при сворачивании приложения (background). Появляется «Доступно офлайн».
4. **Офлайн-режим.** Авиарежим → курс открывается из списка, видео играет (включая перемотку), прогресс отмечается.
5. **Выход из сети и возврат.** Синхронизация прогресса после возврата сети — один раз, без дублей.
6. **Перезапуск.** Закрыть приложение полностью, переоткрыть из «главного экрана» в авиарежиме — курс доступен (перезапуск PWA без сети).
7. **Перенос устройства.** Второе устройство по той же ссылке → «Перенести вход» → на первом устройстве в течение 10 секунд появляется «Сессия завершена», скачанный офлайн-курс удаляется.
8. **Восстановление.** Удалить данные сайта (Настройки → Сайты → данные) или переустановить приложение → «Восстановить доступ» по email → доступ и офлайн-пакет восстанавливаются (пакет скачивается заново).
9. **Срок лицензии.** Не открывать приложение 24 часа → курс требует сеть; после подключения лицензия обновляется.
10. **Хранение.** Проверить в настройках браузера, что сайт использует постоянное хранилище (persistent), если доступно в настройках Chrome.

## iOS Safari

1. **Установка PWA.** Поделиться → «На экран "Домой"». Иконка и имя корректны; приложение открывается в полноэкранном режиме.
2. **Онлайн-просмотр.** Контент всех типов открывается; видео играет и перематывается. Обратите внимание на iOS: аудио запускается только после жеста.
3. **Скачивание офлайн.** «Скачать курс» → прогресс. На iOS фоновая загрузка ограничена — держите приложение открытым до завершения.
4. **Офлайн-режим.** Авиарежим → курс открывается из списка, видео играет.
5. **Перезапуск.** Закрыть и открыть заново в авиарежиме — курс доступен.
6. **Перенос устройства.** Та же проверка, что на Android: SESSION_REPLACED на старом устройстве ≤ 10 секунд.
7. **Восстановление.** Очистка данных Safari для сайта (или «Стереть данные» в iOS) → восстановление по email.
8. **Прогресс.** Отметка урока и синхронизация после возврата сети — без дублей.

## Общие проверки безопасности

- Ссылка в email открывается только во fragment (`#access=`), после активации фрагмент исчезает из адресной строки.
- В DevTools/network нет прямых обращений к MinIO (`object_key` не передаётся); в proxy mode все запросы same-origin.
- Повторное открытие использованной ссылки восстановления — «ссылка недействительна».
- Логи контейнеров `docker compose logs api` не содержат токенов, паролей и подписей S3.

## Критерий прохождения

Все пункты без «частично»; любые баги — в трекер с шагами воспроизведения, устройством и версией браузера. После исправления регресс-прогон E2E (`npm run test:e2e` и `test:e2e:pwa`) обязателен.
